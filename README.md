# PM Grid

PM 기획 산출물을 **템플릿을 고민하지 않고** 캔버스·스프레드시트에서 그린 뒤, 피그마(SVG 레이어)와 엑셀로 보내는 도구입니다.

PM Grid는 수업·실무에서 내는 **개인 및 팀별 산출물 작업과 버전 관리**를 통해
피그마를 포함한 외부 툴으로 유연한 내보내기를 지원하여 기획 단계의 산출물 관리를 효율적으로 돕는 것이 목표입니다.

## 두 가지 사용

| | 이 저장소 (오픈소스) | 배포 버전 (예정) |
|---|---|---|
| 누구 | 개인, 로컬 | 구글 로그인 팀 |
| 저장 | 브라우저 로컬 / JSON 파일 | Supabase, 팀 코드, 히스토리 20개 |
| 실행 | `index.html`을 브라우저로 열기 | Vercel URL |

로컬만 쓰려면 클론 후 `index.html`을 열면 됩니다. 서버 없습니다.

```bash
git clone https://github.com/THRILLUV/PM_Grid.git
open index.html
```

또는 폴더에서 정적 서버:

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765/
```

## 1차 범위 (지금 소스)

- 서비스 플로우 (캔버스 노드, 포트 연결, 줌/팬)
- 유저 스토리보드
- 정보구조도 (스프레드시트, 엑셀보내기)
- 화면설계서
- 내보내기: PNG, 레이어 SVG (피그마), PDF, JSON

## 이후 (배포 버전)

- 구글 로그인, 개인 보드 + 팀 코드
- 저장 히스토리 20개 (누가·언제)
- 수업 5역할별 IA 구간 작업 → 취합 → 피그마
- 산출물 가이드(수업 Master 시트 4)에 있는 나머지 문서들도 같은 방식으로 확장
